# Mixamo .vrm Characters

This repo:
- Hosts selected Mixamo characters in .vrm format - for download and use in your three.js projects.
- Shows a simple step-by-step workflow to convert a character, that you downloaded from Mixamo, from .fbx format to .vrm format. To convert, paste the provided Python script into the Blender application (it's free) and click the play button.
